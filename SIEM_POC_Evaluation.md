# SIEM Proof of Concept (POC) & Capability Evaluation Matrix

This document outlines the evaluation criteria and active implementation status of the SIEM platform's core security components, threat hunting capabilities, and data ingestion pipelines.

## 1. Email Security & EDR

| Feature / Criterion | Description | Implementation Status |
| :--- | :--- | :--- |
| **Attachment Sandboxing** | Isolates and detonates suspicious email attachments in a virtual environment. | In Roadmap |
| **Phishing URL Detection** | Analyzes email links against threat intel databases (e.g. VirusTotal). | Implemented |
| **Endpoint Isolation** | Quarantines a compromised host from the network automatically. | In Roadmap |
| **Process Tree Monitoring** | Tracks parent-child process execution chains on the endpoint. | Implemented |

## 2. Log Pipeline & SOAR

| Feature / Criterion | Description | Implementation Status |
| :--- | :--- | :--- |
| **Syslog / API Ingestion** | Supports standard log ingestion formats (JSON, CEF, Syslog). | Implemented |
| **Log Parsing & Normalization** | Standardizes disparate logs into a unified JSON format (Elasticsearch). | Implemented |
| **Automated Playbooks** | Triggers predefined response actions upon specific alert generation. | In Roadmap |
| **Threat Intel Integration** | Enriches raw logs with malicious IPs/Domains automatically. | Implemented |

## 3. SIEM Core Features

| Feature / Criterion | Description | Implementation Status |
| :--- | :--- | :--- |
| **Role-Based Access Control** | Restricts views and actions based on user roles (L1, L2, L3). | Implemented |
| **Multi-Tenancy** | Segments data and dashboards per client or organizational unit. | Implemented |
| **Real-Time Log Explorer** | Live tailing of streaming logs with advanced filtering capabilities. | Implemented |
| **ISMS Compliance Reporting** | Generates ISO/IEC 27001 aligned reports based on active threats. | Implemented |

## 4. Detection Methods & POC Testing

| Feature / Criterion | Description | Implementation Status |
| :--- | :--- | :--- |
| **Threshold Alarms** | Detects volumetric attacks like Brute Force or DDoS (e.g. Password Spraying). | Implemented |
| **Shannon Entropy Scoring** | Identifies obfuscated or DGA-based malicious payloads. | Implemented |
| **Match Alarms** | Triggers on precise IOCs or specific command executions (e.g. PowerShell bypass). | Implemented |
| **Long-tail Analysis** | Visualizes rare events using statistical stack counting. | Implemented |
